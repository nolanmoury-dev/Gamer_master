# Gamer Master – mise en ligne
1. Supabase : crée un projet, colle `schema.sql` dans SQL Editor > Run.
2. GitHub : mets tout ce dossier dans un dépôt.
3. Vercel : Import du dépôt, puis Settings > Environment Variables :
   SUPABASE_URL, SUPABASE_SERVICE_KEY (clé service_role), SECRET (phrase longue au hasard), OPERATOR_PSEUDO (ton pseudo).
4. Crée ton compte avec exactement ce pseudo : il devient opérateur.
5. Google : Search Console > ajoute l'URL > copie la balise meta dans index.html (google-site-verification) > Sitemaps : sitemap.xml > Demander l'indexation.
6. Remplace TON-SITE.vercel.app dans robots.txt et sitemap.xml.
